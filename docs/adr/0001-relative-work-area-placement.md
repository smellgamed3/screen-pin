# 以可用工作区的比例保存普通窗口布局

用户在 Q8 确认，预设应优先保持窗口占屏布局。因此普通窗口的位置和大小相对于目标显示器的可用工作区按比例保存，任务栏等系统保留区域不计入基准；最大化作为独立状态保存。

相比固定像素或固定视觉尺寸，这让分辨率、缩放和工作区变化时的布局含义保持一致，代价是窗口的像素尺寸、视觉尺寸及可显示内容量可能变化。该语义影响所有持久化预设，后续不能无提示地改为另一种坐标含义。

设计复核进一步明确：普通布局以用户可见的窗口外框为准，包含标题栏和可见边框，排除不可见调整边框；配置保存完整比例精度。系统外框及正常还原矩形的坐标转换由 Windows 适配层负责，最大化状态独立保存。此约定须通过混合 DPI 与连续 20 次捕获／恢复不累计漂移的验证，再固化配置格式。
