# Screen Pin 验收与质量门槛

状态：实现与验收进行中。下述内容定义发布门槛，实际证据另记于 [阶段验收记录](validation/phase-8.md)；未明确取得证据的项目仍属未验证。性能指标是目标，不能视为已测结果。功能约定以 [design.md](design.md) 为准。

## 易用性验收

| 场景 | 通过条件 |
| --- | --- |
| 首次使用 | 清空测试配置后首次显式启动出现主界面；新用户仅凭界面说明完成记住、移动、恢复一个窗口；目标 60 秒内完成 |
| 日常操作 | 每次记住或恢复只需一个热键；成功与失败提示均不抢焦点，后续输入进入原窗口 |
| 默认与特定规则 | 界面预览和结果能区分应用默认及具体关键字；标题变化回退后明确显示共享范围；不弹出反复确认框 |
| 查看旧方案 | 查看非活动方案不改变热键路由；非活动方案只读，当前窗口不能覆盖旧环境预设 |
| 撤销 | 托盘一级入口及主界面均可找到；覆盖恢复旧值，新建删除该条；相同内容重复记住不冲掉上一次有效撤销 |
| 关联屏幕 | 可在实际屏幕显示临时标记，完成一对一关联；取消不留下半完成配置；无需识别设备路径 |
| 键盘和读屏 | 仅键盘能选择窗口、保存、编辑、排序、撤销、退出；Tab 顺序与焦点清楚；Narrator 可读名称及状态 |
| 显示适配 | 100%／150%／200% 缩放、系统大字体及高对比度下关键内容无裁切，错误不只用颜色表达 |

首次使用结果需记录操作者是否已熟悉工具；开发者自己的操作不视为独立易用性验证。

## 功能与可靠性场景

| 编号 | 场景 | 必须满足的结果 |
| --- | --- | --- |
| F01 | 无预设、仅默认、单条特定、多条特定同时匹配、标题变更 | 恢复和更新选择一致；首条特定优先；无匹配更新只建默认；无匹配恢复仅提示 |
| F02 | 浏览器／编辑器主窗口与其文件选择、临时对话框 | 主窗口可用；临时窗口不创建或覆盖默认，也不暗中操作背后窗口 |
| F03 | 热键后切换焦点、目标关闭、句柄复用、编辑规则、操作中拔屏 | 不操作新前台或错误窗口，不写入其他方案；过期命令有明确结果 |
| F04 | 插拔、唤醒、扩展坞中间拓扑；未知组合和身份不明组合 | 稳定后才选方案；确定新组合用空方案；身份不明暂停关联，不反复生成中间空方案 |
| F05 | 两台同型号屏幕、互换位置或接口、重启 | 明确身份时跟随原物理屏；不明时可关联；临时编号和枚举顺序不决定永久身份 |
| F06 | 普通窗口、混合 DPI、负坐标、任务栏位于顶部或左侧、分辨率变化 | 依据可用工作区比例恢复；没有因坐标系混用造成累计偏移 |
| F07 | 同环境连续“记住→移动→恢复”20 次，打开并保存未改动的编辑表单 | 可见边界与基准各边误差不超过 2 个物理像素且不随次数累计；未改动字段不因显示舍入改变配置 |
| F08 | 最大化捕获、跨屏恢复、之后手动还原；任务栏自动隐藏 | 捕获不闪烁还原；目标屏及状态正确；还原矩形合理；正常最大化不误判全屏 |
| F09 | 疑似全屏、强制最小尺寸、窗口自调整、无响应窗口 | 跳过或诚实报告受限／未确认；无无限重试，不将实际偏差自动写入预设；随后其他操作仍可用 |
| F10 | 长按更新、忙时再次按键、完全相同的更新 | 不积压命令，不重复写盘、不覆盖有效撤销记录；忙碌反馈明确 |
| F11 | 外部占用新热键、两个动作同键、互换热键、注册或保存失败 | 同键拒绝；交换映射正确；失败保留旧有效绑定；界面反映实际注册状态 |
| F12 | 写临时文件失败、替换失败、规则编辑与更新交错 | 磁盘、内存和撤销记录一致；只有持久化成功才提示成功；不丢失其他配置 |
| F13 | 热键／GUI 捕获／表单创建及覆盖后撤销、连续编辑同条、无关设置或排序、删除或重新关联 | 每次有变化的创建／覆盖生成最近记录；连续编辑撤回最后一次；无关设置或排序不丢失；删除或关联造成语义变化时失效；版本冲突不覆盖新内容 |
| F14 | 截断 JSON、非法字段、未来版本、损坏主文件及有效／无效备份、迁移失败 | 保留原件及最后有效备份；不静默清空，不用旧格式覆盖未来格式；恢复有可操作入口 |
| F15 | UAC 取消、跨账号凭据、初始化或接管失败、交接中第三次启动 | 原实例保持或恢复可用；只有一个写入者；不误用其他账号配置；没有双实例并发写入 |
| F16 | 已提权实例再次普通启动、Explorer 重启、关闭界面、退出、可选自启 | 显示已有界面，托盘可重建；关闭不退出，退出释放热键；自启默认关闭且使用正确路径 |
| F17 | 打包应用正常版本升级、普通应用同名不同路径、宿主窗口 | 稳定打包身份仍命中；不同桌面路径不误合并；无法归属的宿主窗口不覆盖其他应用 |
| F18 | 重启、覆盖升级 ZIP、没有开发工具链的干净 Win11 x64 环境 | 配置保留，程序可启动、捕获、恢复与退出，无未随包满足的运行依赖 |

以受支持且响应正常的样本验证 F07 的精度；应用明确施加尺寸约束时归入 F09，必须展示受限结果，不能算精确恢复通过。

## 响应与资源目标

| 指标 | 首版目标 | 测量方法 |
| --- | --- | --- |
| 普通启动 | 已有配置时 1 秒内热键及托盘就绪；首次主界面 1.5 秒内可操作 | Release 包，记录 CPU、系统、磁盘和应用版本；测量进程启动至就绪，不含用户解压时间 |
| 正常恢复 | p95 不超过 300 ms | 从收到热键至实际结果被确认；同屏和跨 DPI 分别至少 50 次，记录全部样本及异常原因 |
| 无响应目标 | 2 秒内给出未确认／失败结果并释放操作槽 | 人为挂起目标窗口；托盘与界面仍响应，下一次其他窗口操作能执行；已投递异步请求可能晚到须如实说明 |
| 托盘空闲 CPU | 60 秒累计 CPU 时间不超过 300 ms，即一个逻辑核的 0.5% | 无用户操作、拓扑稳定、无活动通知；记录进程 CPU 时间增量，检查没有持续窗口轮询 |
| 内存 | 稳定托盘空闲私有提交不超过 50 MiB；主界面不超过 80 MiB | Release 包启动稳定后及 100 次操作后测量 Private Bytes，观察持续增长 |

这些数值是初始工程预算。未达标时先定位原因，保留测量记录；如确需修改目标，记录理由与取舍，不能把未测或失败写成通过。实际应用响应约束要单列，不掩盖工具自身耗时。

## 测试分工与发布阻断项

纯逻辑和可控 Adapter 测试覆盖规则、比例转换、更新与撤销、版本校验、失败注入及事务提交。Windows 集成测试验证窗口过滤、API 结果、真实 DPI、热键注册和文件替换。实机交互验证多屏、提权、焦点、可访问性、首次使用和发布包。

以下问题阻断首版发布：错误窗口或错误方案被操作、误覆盖有效配置、失败被报告为成功、输入焦点被反馈抢走、主界面或托盘因目标无响应持续卡住、热键修改失败导致原有效绑定被丢弃、提权产生并发写入者。

发布记录必须包含测试日期、应用与系统版本、屏幕和缩放组合、各项结果、性能样本及已知限制。缺少硬件或权限的项目标记未验证；不能用纯逻辑测试替代物理多屏和权限验收。
