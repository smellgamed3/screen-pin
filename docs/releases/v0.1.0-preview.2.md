# Screen Pin 0.1.0 Preview 2

新增置顶编辑模式：勾选顶部开关，点击其他应用即可自动识别窗口并实时显示位置和大小。回到面板直接记住、更新或恢复刚才的目标，原有热键也可在面板内使用。其他应用正常操作；取消、最小化或回托盘结束编辑模式。

配置与 Preview 1 兼容。退出旧实例后解压运行新 EXE，保留 `%LOCALAPPDATA%\ScreenPin`。最小化目标需先还原；切换最大化状态时仍须聚焦目标后按热键。

通过格式检查、严格 Clippy、66 项库测试，以及三个新建 Sandbox 中编辑模式 23 项、外观 1,251 项和基本分发 47 项检查。包含真实面板恢复热键、连续目标切换、草稿及正常退出。详情和先前失败见 [阶段 28](../validation/phase-28.md)。

这是开发预览。物理多屏、混合 DPI、真实 UAC、Narrator、首次使用计时、重启登录和新版完整宿主应用回归仍待验收。Preview 1 的 23 项历史组件证据不自动继承。
