# Screen Pin v0.1.0-preview.1

2026-10-18 · Windows 11 x64 · 开发预览

记住应用窗口在指定显示器的位置和大小，按热键随时恢复。此版供个人日用试用，完整实机验收尚未结束。

## 下载与使用

下载附件 `ScreenPin-0.1.0-windows-x64.zip`，解压后运行 `screen-pin.exe`；无需安装 .NET 或 WebView。ZIP 内程序版本为 0.1.0，发布标签使用 preview.1 表明验收状态。

1. 把目标窗口放到希望的位置和大小。
2. 聚焦目标窗口，按 **Ctrl+Alt+F10** 记住。
3. 移动窗口后，按 **Ctrl+Alt+F9** 恢复。

默认按应用共享预设，可按窗口标题关键字设置特定规则。每种显示器组合保留各自方案；切换方案本身不移动窗口。托盘和配置界面可管理规则、修改热键和撤销最近一次预设更新。

最小化窗口请先从任务栏还原，再按恢复热键。全屏、临时对话框及工具自身窗口会跳过。退出程序请使用托盘菜单。

配置保存在 `%LOCALAPPDATA%\ScreenPin`，替换程序时保留。开机启动默认关闭，默认使用普通权限。

## 验证范围

- 发布 ZIP 与此前验测候选逐字节相同，没有为发布重新构建应用。应用源码最后变更于 `9f4520d12ca63102c875e311cbce762a09b5e149`；其后的提交补充测试驱动、诊断和文档。
- 当前二进制累计 19 项回归组件有通过证据，包含干净 Windows Sandbox 基本流程、热键、配置故障与恢复、草稿冲突、竞态、启动、大字体／高对比度阅读、资源占用和开发构建覆盖升级。
- 隔离环境中 100 次真实热键循环通过，恢复耗时 p95 约 16.685 ms；该数值仅描述该次测试环境。
- 用户已反馈正常窗口的保存与恢复成功。

确认框键盘、托盘键盘及两组实际应用兼容性仍需宿主复测。九项隔离夹具矩阵中七项通过，另外两项被 UIA 进程归属检查阻止，因此矩阵整体未通过；19 项组件证据不代表完整验收通过。

物理多屏／混合 DPI、真实 UAC、Narrator、独立首次使用计时和系统重启登录仍待验证。此版未宣称已达到最终稳定版验收标准。

详细记录见[阶段 24](../validation/phase-24.md)、[需求覆盖](../validation/coverage.md)和[实机操作单](../validation/manual.md)。历史文档中的 `artifacts` 链接指向未随仓库上传的本地原始测试材料，GitHub 上仅提供已提交的验证摘要。
