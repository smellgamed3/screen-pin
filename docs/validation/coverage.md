- 格式、严格 Clippy、all-targets 60 项测试通过，包含事务／撤销、存储保护／跨进程启动锁、显示器匹配、热键事务和托盘重建。测试源码不等于所有真实系统场景均已通过。
- 当前 ZIP 独立解压后 34 条 GUI 断言通过，EXE 与 Release 哈希一致，只含 EXE 和 README；自建实例正常退出。
- 当前 Release 键盘脚本 177 条检查通过：捕获、表单保存、撤销、规则创建及排序；三页正反向 Tab 遍历全部启用控件，96 次焦点观察完整可见。62 条原生 UIA 样本名称／角色已核对。
- 当前 Release 真实 SendInput F10／F9 完成 100 次完整循环，边界误差 0 px；可见匹配 p95 16.193 ms，明确成功反馈 p95 32.895 ms。初次可用系统 UIA 聚焦自建 fixture，后续输入持续校验实际前台。
- 当前 Release 后台 shell 命令完成 300 次循环；目标暂停 1.2 s 时约 259 ms 返回未确认、host 和配置窗口保持响应，重叠命令被拒且未写配置；尺寸约束如实报告受限。
- 300 次循环按阶段采样，私有内存峰值约 2.824 MiB，未见持续单调增长；操作后空闲 60.606 s CPU 计数无可测增量。另一次空配置空闲 60.723 s CPU 15.625 ms，托盘峰值约 2.051 MiB、界面约 2.059 MiB。仅描述有界本地观察。
- Brave 155.1.97.59、VS Code 1.130.0 独立 profile 的普通主窗口 GUI 捕获／恢复各边误差 0 px，前台保持，主进程正常退出，按唯一 profile 路径扫描无残留。

本轮还修复了保存时禁用按钮造成键盘焦点清空、只读多行结果框拦截 Tab，以及关联预览名称为空三处实测问题。真实 Narrator 试听、托盘纯键盘退出和全部确认对话框仍未由上述脚本证明。
