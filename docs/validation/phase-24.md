## 隔离驱动和失败复盘

`scripts/sandbox-smoke.ps1 -Fixtures` 将既有验证脚本、原 ZIP 和测试探针复制到只读输入目录，并把现有 PowerShell 7 测试运行时只读映射给来宾。不是向系统安装 SDK 或运行时，也不把测试工具当作 Screen Pin 的依赖。每个测试使用来宾本地配置目录，退出后才把原始证据复制到输出映射；测试按键只在来宾会话中发出。

宿主入口继续拒绝接管已有 Sandbox，只停止本次新建的 GUID；来宾校验固定路径、模式、WDAGUtilityAccount、虚拟机身份及与宿主不同的计算机名。初始真实标题栏点击只在明确启用的来宾测试驱动中允许，核对目标 PID、顶层 HWND 和点击点归属，恢复鼠标并取消临时置顶。宿主默认不启用，伪造宿主启用和直接在宿主调用来宾脚本的只读保护检查均已拒绝。后续每次按键仍校验实际前台。

保留的失败和结论：

- c182a1d6、60d98c3f：热键测试在反馈控件单次 50 ms 读取上退出；新增堆栈与快照确认首次捕获已成功、前台仍是夹具。只在既有总等待上限内重试该只读超时并计数，实际性能计时和 300 ms 门槛不变。
- 835d6bd7：完成十轮后遇配置替换拒绝访问。给测试配置观察器统一使用 FileShare.ReadWrite | Delete，避免阻止原子替换；962dead2 在输出映射目录中仍失败，因此不能把映射目录失败完全归因于读取句柄。
- 6c16a693：改用来宾本地配置、完成后复制证据，100 轮通过。映射目录上的拒绝访问保留，不声称已修复或验证该文件系统的写入支持。
