# 实机验收操作单

本单用于补充脚本不能证明的硬件和交互结果。完整门槛见 [acceptance.md](../acceptance.md)，已有证据见 [coverage.md](coverage.md)。未执行的行保持“未验证”，不按开发者预期填写通过。

## 记录环境

记录测试日期、ZIP 和解压后 EXE 的 SHA256、Windows 版本、应用版本，以及每台屏幕的型号、连接方式、分辨率和缩放。若当前系统不具备某个条件，写明缺少的条件。

可为每轮测试使用独立配置，避免改动日用预设。在解压目录的 PowerShell 中运行：

```powershell
$screenPinTestDir = Join-Path $env:LOCALAPPDATA ('ScreenPin-Acceptance-' + [Guid]::NewGuid().ToString('N'))
& .\screen-pin.exe --show --config-dir $screenPinTestDir
```

关闭主界面只是隐藏；一轮结束从托盘退出。不要同时运行多个不同测试配置争用同一对热键。手动记录预设基准时保存截图和实际边界，不能只凭“看起来差不多”判定精度。

已有 Windows Sandbox 的机器可运行 `pwsh -NoProfile -File scripts/sandbox-smoke.ps1` 补充干净隔离桌面的发布包检查，结果范围见 [阶段 20](phase-20.md)。脚本拒绝接管已有 Sandbox，使用单独输入／输出目录并只清理自身创建的实例；这不替代下列物理设备和人工结果。真实来宾 Explorer 重启及 Run 项启用／路径修复／关闭可执行 `pwsh -NoProfile -File scripts/sandbox-smoke.ps1 -Lifecycle`，边界见 [阶段 21](phase-21.md)；不计为重启登录通过。

## 操作与判定

| 项目 | 操作 | 判定及应记录内容 |
| --- | --- | --- |
| 独立首次使用 | 请未用过工具的人首次启动，只阅读界面，摆好测试窗口，记住、移动并恢复 | 记录是否熟悉工具及用时；目标 60 秒内完成，无口头提示；写下犹豫或误操作处 |
| 真实应用 | 使用浏览器、资源管理器、VS Code、Terminal 等实际可用样本；检查普通、最大化、标题变化和临时文件对话框 | 主窗口命中正确默认／标题规则；对话框拒绝且不改背后窗口；记录应用精确版本及不兼容状态 |
| 编辑与热键 | 在独立配置中改预设百分比但先不保存，切到自建测试窗口按 F9，再回到表单；再用 F10 更新同一预设后尝试保存旧草稿，最后明确刷新 | F9 后草稿保留；F10 冲突提示明确，旧草稿保存被拒且新预设不被覆盖；明确刷新才放弃冲突草稿并显示当前值 |
| 设置草稿 | 在独立配置中填写新热键但先不保存，切到自建窗口用原热键恢复／更新，再刷新并查看其他方案；尝试保存重复热键，修正后明确保存并重启 | 未保存输入保留，注册状态仍显示原热键；失败可重试；保存成功才切换实际映射，重启与已保存值一致。自启保持关闭；忙时及保护模式下设置字段禁用 |
| 多屏与缩放 | 两屏设为不同缩放，含左侧负坐标；每屏捕获和恢复，循环 20 次；测试最大化后手动还原 | 预设跟随目标物理屏；普通可见边界各边误差 ≤2 px、无累计漂移；还原矩形正确；记录每轮误差 |
| 屏幕身份 | 在有可恢复连接方式的条件下，交换位置／接口，插拔、唤醒，使用同型号屏幕或扩展坞 | 已确认身份跟随物理屏；歧义明确要求关联；取消关联不改配置；稳定后不出现多余中间方案；旧方案仍在 |
| 权限交接 | 先取消管理员重启，再同账号允许；交接时再普通启动一次；如有条件测试跨账号凭据及初始化失败 | 取消后原实例可操作；成功后只有一个写入者、热键和托盘可用；普通重复启动显示现有界面；跨账号不接管原账号配置；保留错误及进程日志 |
| 键盘与读屏 | 用 Tab、Shift+Tab、助记键完成选择、记住、编辑、排序、撤销及退出；开启 Narrator 阅读字段和结果 | 全流程可完成，焦点清楚且滚动到可见位置；名称和状态可读，记录无名称、重复或读错的控件 |
| 字体和对比度 | 在可控测试桌面验证 100%／150%／200%、系统大字体和高对比度 | 关键字段、按钮和错误无裁切；焦点和禁用状态可辨；保存各页截图并记录设置 |
| 生命周期与分发 | 在测试机验证 Explorer 重启、自启实际登录；干净 Win11 x64 解压运行；原目录覆盖升级后复测 | 图标恢复、原实例仍可用；自启默认关闭，启用与移动路径修复均有效；无开发工具链仍可捕获／恢复／退出；配置保留 |

系统登录、Explorer 重启、显示设置和 UAC 测试需要操作者控制桌面；在专用测试机或方便恢复的会话执行，并记录设置恢复情况。本地消息模拟不填为真实 Explorer／UAC 通过。

## 结果格式

每个场景记录：`场景 → 环境 → 步骤 → 期望 → 实际 → 通过／失败／未验证 → 原始证据路径`。失败应保留测试配置、截图、精确提示和复现步骤；含窗口标题或设备标识的原始报告保存在本地，不直接提交到仓库。

大字体和高对比度可在隔离 Sandbox 中执行 `pwsh -NoProfile -File scripts/sandbox-smoke.ps1 -Appearance`。阶段 22 的阅读失败已在阶段 23 当前候选上复测通过，详见[阶段 23](phase-23.md)；不能外推为物理混合 DPI 或全部缩放验收通过。它会实际改变自身来宾的字体和主题，宿主设置不变。确认框／托盘在来宾中的 UIA 环境差异见[阶段 25](phase-25.md)，相关宿主键盘复测仍待执行。
