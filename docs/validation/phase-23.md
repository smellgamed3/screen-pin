## 独立首次使用

用户已表示现在可以安排未用过工具的操作者。本轮为其新建独立配置，将上述 EXE 复制到专用目录并记录哈希；启动 Screen Pin 和“窗口位置测试”。首次配置为空，不预先建立示范预设，不向操作者提示按键或具体操作方法。

任务为保存测试窗口位置、移开并恢复；从操作者读到任务时计时。用户随后确认“已经测完”，并反馈“保存恢复正常，但窗口最小化时修复是否生效？”。已记录保存／恢复成功，以及最小化行为的疑问；首次使用身份、用时及是否求助未提供，不能推定通过独立新用户 60 秒门槛。当前实现拒绝最小化目标并提示先还原，该反馈不记为故障或新功能要求。

人工测试期间未向宿主注入自动按键、切换焦点或打开 Sandbox 桌面连接。用户明确结束后，已正常收起专用实例及夹具；会话无错误，最终可见矩形与初始矩形相同，但此间快照不证明用户曾移动窗口或操作耗时。原始记录为 artifacts/usability/manual-7e2afd348ff640159cde4891122b531e 下的 session.json、operator-feedback.json 和独立配置。

恢复 GUI 回归后的首轮 Sandbox（9bb70ebf-a052-4fbd-8386-024f4eac2e48）在初次聚焦夹具时失败，尚未进入字体场景。证据显示专用聚焦及主题清理函数定义位于初次调用之后，实际使用了通用 UIA 聚焦，清理也无法调用尚未定义的 Wait-Theme。已将这些函数定义移到初始化之前，保留失败报告并重跑；不以该准备阶段失败判断字体修复成败。

第二轮（91efbe05-04f6-486c-b794-f2d926469f86）取得普通字号 53 个文字样本且未见溢出，但新增 Home 键检查误用 PowerShell 只读自动变量 HOME，导致脚本退出。已改用 firstAfterHome；不把部分样本计为完整通过。
