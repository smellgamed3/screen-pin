## 剩余四项宿主回归

先确认连续约五分钟桌面空闲，期间不操作鼠标键盘，再顺序执行。此时间为安排估计；测试超时、焦点变化或任一断言失败均保留失败，不能把部分执行当作完整通过。每个入口使用独立配置和自建测试窗口／profile；原有身份、前台、清理和正常退出检查继续执行。

| 顺序 | 入口 | 要补齐的证据 |
| --- | --- | --- |
| 1 | `pwsh -NoProfile -File scripts/dialog-keyboard-smoke.ps1` | 迁移、关联和新建配置确认框的真实键盘、默认否、取消、确认与焦点返回，UIA 按钮名称／角色 |
| 2 | `pwsh -NoProfile -File scripts/tray-keyboard-smoke.ps1` | 实际 Win+B／Shift+F10、托盘撤销／打开／退出、撤销不移窗口和退出释放热键 |
| 3 | `pwsh -NoProfile -File scripts/application-smoke.ps1 -PrecisionCycles 20 -ExtendedStates -TemporaryDialogs -Fullscreen -HotkeyStates -HotkeyCycles 50 -TitleRules` | Brave／VS Code 独立实例的精度、最大化／最小化、临时对话框／全屏拒绝、真实热键和动态标题规则 |
| 4 | `pwsh -NoProfile -File scripts/shell-apps-smoke.ps1 -Cycles 20 -HotkeyStates -TitleRules` | 新建 Explorer／Terminal 窗口的对应状态、包身份、标题规则、精度和真实热键 |

本轮仅核对入口和已安装 Brave／VS Code 的文件版本，分别为 155.1.97.59／1.130.0，没有执行上述前台回归。应用可能自行升级，实际验收仍记录执行时版本。运行前确认没有日用 Screen Pin 实例争用热键，并核对 `target/release/screen-pin.exe` 仍是上述候选；原生 UIA 探针需预先构建。脚本不接管已有测试进程。阶段 25 的 Sandbox UIA 差异继续作为未解决环境问题保留。
